# Java Kitchen Simulation & Test Suite

A robust object-oriented Java application modeling complex kitchen workflows, inventory state transitions, and order fulfillment mechanics. Developed as part of computer science coursework at Eötvös Loránd University (ELTE).

Key Features

⚬ Object-Oriented Architecture: Implements clean class hierarchies and encapsulation to manage entities such as chefs, meals, meal types and kitchen.
⚬ Robust State Management: Handles dynamic preparation workflows, and state transitions.
⚬ Comprehensive Test Coverage: Backed by JUnit unit test suites verifying edge cases, component interactions, and runtime reliability.

Tech Stack & Tools

⚬ Language: Java (OOP principles)
⚬ Testing Framework: JUnit
⚬ Development Environment: VS Code

Testing & Quality Assurance

The codebase emphasizes reliability through automated testing. The test suite covers:

⚬ Individual component unit tests for inventory and workflow management.
⚬ State validation tests ensuring correct order lifecycle progression.
⚬ Edge-case handling for resource constraints and inputs.

To run the test suite locally:

# Using Maven (if configured)
mvn test

# Or compile and run via your IDE


Engineering Highlights

⚬ Designed with modularity to allow seamless extension of new kitchen stations or recipes.
⚬ Emphasizes clean code standards, defensive programming, and predictable exception handling.
